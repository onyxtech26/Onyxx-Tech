The brief

R-Star POS handles the full shop workflow which are POS that sell items. Inventory that batches, stock levels, product conversions, and an immutable stock-movement ledger. Stock counts which daily cycle counts with variance reasons and theft/shrinkage tracking. Reports for business-day sales, profit/COGS, discounts, payment breakdown, and daily cash settlement.

What we built

A Flutter desktop application backed by local SQLite, so the till keeps working when the shop's internet does not — with an append-only stock ledger that records every movement rather than overwriting a quantity.

The stack

Flutter, Dart, JavaScript, SQLite — chosen to fit the job rather than to pad a list. Every project we take on is scoped so the client owns the code and the accounts at the end of it.

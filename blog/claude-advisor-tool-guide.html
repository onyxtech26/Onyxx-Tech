Claude's advisor tool: pay for the expert only when you need one

A cheaper Claude model does the work and calls a smarter one only for the hard decisions. Here is what that means, what it costs and how to switch it on.

By Onyxx Tech27 November 20266 min read

Download as PDFFree. Save it, print it, share it with your team.

The advisor tool lets a fast, low-cost Claude model do the work and call a smarter Claude model, such as Claude Opus, only when it reaches a hard decision. The smart model reads everything so far, sends back a short plan, and the cheaper model carries on. You get results close to the smart model's quality while most of the writing is billed at the cheaper model's price. It is in beta on the Claude API, and switching it on takes one extra tool in your request.

The problem: paying expert rates for easy work

Most AI agents run one model for every step. If that model is the smartest one, you pay top price to rename files, reformat text and read search results. If it is a cheaper one, it does those steps well but sometimes picks the wrong plan on the hard part, and the whole job goes off course.

Think of an office. You would not pay a senior consultant to do data entry. You would let a junior do the work and call the consultant for twenty minutes when a real decision comes up. The advisor tool is that arrangement, built into the API.

How does the advisor tool work?

There are two models in one request:

  1. The executor is the model you call as usual (for example Claude Sonnet 5.5). It does the work and writes the final answer.
  2. The advisor is a smarter model you name inside the tool (for example Claude Opus 5.5).

The executor decides when to ask, the same way it decides to use any other tool. When it does, the advisor runs on Anthropic's side and receives the whole conversation so far: your instructions, the tools, earlier turns, tool results and the work in progress. The advisor has no tools of its own. Its reply is a short piece of advice, and only that advice goes back to the executor (the advisor's own thinking is dropped). The executor then continues. All of this happens inside one API request, so you do not write any extra back-and-forth code.

Anthropic's advisor tool page has a diagram of the full flow.

What do you actually get?

Quality close to the smart model, at a price close to the cheap one. The advisor usually writes a short note, roughly 400 to 700 tokens of advice per call according to Anthropic, while the executor writes everything else at its lower rate.

Anthropic's own tests, reported on the same page, give a feel for it:

  • A Claude Sonnet executor at medium effort with an Opus advisor reached about the same intelligence as Sonnet at its default effort, at a lower cost.
  • Capping each piece of advice at 2,048 tokens cut the advisor's output about seven times, with almost no advice cut short.

Each advisor call is billed separately at the advisor model's rates, and it shows up in the response's usage.iterations list, so you can see exactly what the advice cost.

When is it worth it, and when is it not?

Use it for long, multi-step jobs where getting the plan right matters: coding agents, research that takes many steps, computer use. Anthropic suggests two common setups:

  • You already run Sonnet on complex tasks: add an Opus advisor and keep a similar or lower total cost.
  • You run a small model like Haiku and want it smarter: add a bigger advisor. That costs more than Haiku alone but less than switching everything to the bigger model.

Skip it for simple one-shot questions, where there is nothing to plan, and for jobs where every single step needs the top model anyway.

How do I turn it on?

Three things go into a normal Messages API request:

  1. The beta flag advisor-tool-2026-03-01.
  2. A tool with type: "advisor_20260301", name: "advisor" and the advisor model.
  3. A top-level model for the executor.

The advisor must be at least as capable as the executor, or the API returns an error. A Claude Sonnet 5.5 executor with a Claude Opus 5.5 advisor is a valid pair.

Python

import anthropic

client = anthropic.Anthropic()

response = client.beta.messages.create(
    model="claude-sonnet-5-5",          # the executor: does the work
    max_tokens=16000,
    betas=["advisor-tool-2026-03-01"],
    tools=[{
        "type": "advisor_20260301",
        "name": "advisor",
        "model": "claude-opus-5-5",     # the advisor: asked only for hard decisions
        "max_uses": 3,                  # at most 3 consultations per turn
        "max_tokens": 2048,             # keep each piece of advice short
    }],
    messages=[{"role": "user", "content": "Plan and write a booking system for a small clinic."}],
)

TypeScript

import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const response = await client.beta.messages.create({
  model: "claude-sonnet-5-5",
  max_tokens: 16000,
  betas: ["advisor-tool-2026-03-01"],
  tools: [{ type: "advisor_20260301", name: "advisor", model: "claude-opus-5-5", max_uses: 3, max_tokens: 2048 }],
  messages: [{ role: "user", content: "Plan and write a booking system for a small clinic." }],
});

A few things worth knowing before you ship it:

  • You may not be able to read the advice. Newer advisors such as Claude Opus 5.5 return it encrypted (advisor_redacted_result). The executor can use it; your code just passes it back in the conversation. If you need to read the advice while testing, Anthropic names claude-opus-4-8 as an advisor that returns plain text.
  • Streaming pauses while the advisor thinks. The stream sends keep-alive pings, so do not treat the silence as a timeout.
  • Turn on caching for long jobs. The tool has a caching option ({"type": "ephemeral", "ttl": "5m"}); Anthropic says it pays off from about three advisor calls in a conversation.
  • Some newer executors cannot be forced to call it (tool_choice of type tool or any is rejected). Ask for it in your system prompt instead, for example "Consult the advisor before you commit to a plan."

What not to do

  • Do not add an advisor to a chatbot that answers simple questions. You pay for advice nobody needed.
  • Do not pair a smart executor with a weaker advisor. The API rejects it, and it would not help anyway.
  • Do not build your own "ask the big model" loop for this. The tool already sends the full context and returns in one request.

Where to start on Monday

Pick one long task your team already runs with a single model, the one that sometimes goes off track. Run it ten times as it is, then ten times with a cheaper executor and the advisor switched on, with max_tokens at 2,048. Compare the results and the cost in usage.iterations. Keep whichever wins.

Questions people ask

Is the advisor tool free?

No. Each advisor call is billed at the advisor model's normal rates, and the executor is billed at its own. The saving comes from the cheaper model writing most of the output.

Which models can be the advisor?

The advisor has to be at least as capable as the executor, and Claude Sonnet 4.6 or newer. Anthropic's advisor tool page lists every valid pair.

Does it work with Claude Code or the Claude app?

It is a Claude API feature for developers building their own apps and agents. It is in beta on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed).

Can the advisor use tools or search the web?

No. It only reads the conversation and gives advice. The executor does all the tool calls.
